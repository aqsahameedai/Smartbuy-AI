SmartBuy AI 🛍️

An AI Personal Shopping Agent — a hands-on demo of agentic commerce.

SmartBuy AI is a browser-based simulation of an AI shopping agent. You describe what you need in plain language ("running shoes under $100", "a gift for a coffee lover, under $50"), and the agent parses your intent, scores a live product catalog against it, and hands you a ranked cart — instead of you filtering, comparing, and searching by hand.

This project explores a specific idea in AI growth & agentic commerce: the shift from people operating storefronts to people delegating outcomes to an agent that operates the storefront for them.
✨ Features
Conversational shopping agent — a terminal-style chat panel where you type what you're looking for in natural language.
Real intent parsing — the agent extracts budget ("under $100", "$40–$60"), category, gift signals, and quality preference from your message using rule-based logic.
Live scoring engine — every product in the catalog is scored against your intent (keyword match, category fit, price fit, rating) and ranked in real time.
24-product catalog across Electronics, Fashion, Home, Sports, and Beauty, with category filters, free-text search, and sort (AI match / price / rating).
Cart & checkout simulation — add items from chat recommendations or the catalog grid, adjust quantities, and check out to a printed-receipt-style order confirmation.
Fully responsive — down to small mobile screens, with a collapsible nav, stacked hero, and a full-width cart drawer on phones.
Zero dependencies — plain HTML, CSS, and JavaScript, all in one file. No React, no npm, no server required to run it.
