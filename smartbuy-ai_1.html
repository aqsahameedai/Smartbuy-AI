The agent loop

Three steps happen behind every reply — this is the same read → reason → act loop agentic-commerce systems run in production, simplified so you can watch it work.

  1. 01

    You state intent

    Natural language in — budget, category, occasion, quality bar. No filters to configure first.

  2. 02

    Agent scores the catalog

    Every listing is ranked live against your intent: keyword match, price fit, rating, gift signal.

  3. 03

    Agent acts on your behalf

    Top matches are surfaced ready to add. One tap moves them from recommendation to cart.

Why this project exists

From search boxes to shopping agents

Agentic commerce is the shift from people operating storefronts to people delegating outcomes to an agent that operates the storefront for them. SmartBuy AI is a small, transparent model of that shift.

Traditional e-commerce

  • You choose filters, categories, and sort order
  • You compare tabs and listings manually
  • You re-search for every new need

Agentic commerce

  • You state the outcome you want in plain language
  • The agent parses intent, scores inventory, and ranks results
  • The agent proposes the cart — you approve or refine it

Fork it, extend it, ship it.

This entire agent runs on rule-based scoring — no backend, no API key. Swap js/agent.js for a real LLM call when you're ready to go further.
